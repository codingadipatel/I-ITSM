COVERAGE
107 Java files; 139 declared types, including 32 nested types.
All production types are detailed on at least one numbered sheet.
Constructors, Lombok-generated getters/constructors and implicit record accessors are omitted.
Explicitly written getters and private helper operations are retained.
JDK/Spring classes are external dependencies: shown in member types or inheritance notes.
Frontend functional components, tests and database tables without Java types are outside the class inventory.

CORRECT INTERPRETATION
- Administrator is the Java class for the ADMIN role; User is abstract.
- User roles use SINGLE_TABLE inheritance. Technician has shared Skill entities.
- Incident has one reporter, an optional assigned Technician, service/category and embedded SlaTracking.
- Nullable JPA relationships retain 0..1 notation; normal service operations impose stronger rules.
- PriorityStrategy and TechnicianAssignmentStrategy are separate interfaces. No IncidentStrategy class exists.
- StateRegistry selects IncidentState objects; IncidentService enforces actor permissions.
- IncidentEmailService is an event listener. SMTP delivery is performed by SmtpOutboxService.
- Chat is persisted through JdbcTemplate; IncidentChatService.Message is a record, not a JPA entity.
- EmailMessage is a projection of selected outbox fields; worker SQL also manages attempts and expiry.
- No obsolete NotificationFactory or SimulatedEmailChannel is included.

LEGEND
+ public; # protected; - private; ~ package visibility.
Hollow triangle: inheritance; dashed hollow triangle: interface realization.
Filled diamond: composition; hollow diamond: shared aggregation.
Solid arrow: stored association; dashed arrow: dependency.
Record components are represented as private final data; generated accessors are omitted.
